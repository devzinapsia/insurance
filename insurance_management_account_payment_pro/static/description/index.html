Gestión de seguros - Pagos de adhoc

Insurance installment payments that pay their own bill

Bridge between Gestión de seguros and adhoc's payments (account_payment_pro): installs automatically.

Key Features

  • Only its installment: the payment of an installment lists only that installment line of the bill in Debts, not every open debt with the insurer.
  • Right reconciliation: posting the payment pays the installment, never an older bill of the same insurer.
  • Existing drafts fixed: draft payments already created get their debts fixed on install.

Developed by Zinapsia for Odoo 19.
