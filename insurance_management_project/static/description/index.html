Gestión de seguros - Proyectos

Surety bonds of projects

Bridge between Gestión de seguros and Project: installs automatically.

Key Features

  • Guaranteed project: a surety bond can point to the project (e.g. a public work) whose fulfilment it guarantees.
  • From the project: the project shows its surety bonds.
