Bridge between **Gestión de seguros** (``insurance_management``) and
**Project** (``project``). It installs automatically when both modules are
present.

* Surety bonds get a *Guaranteed project* (tab *Surety bond*), copied to
  their renewals, visible to project users.
* The project shows the *Surety bonds* smart button (the last policy of each
  renewal chain).
