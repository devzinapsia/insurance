Gestión de seguros - Cheques propios

Pay insurance installments with own deferred checks

Bridge between Gestión de seguros and the checks of the Latin American localization: installs automatically.

Key Features

  • One check per installment: deferred check payment modes using Own checks create a payment with its check dated on the installment due date.
  • Ready for the treasurer: payments are created when the bill is posted, as drafts to fill in the check number and post.
  • Always reconciled: posting the payment pays the installment against the bill.

Developed by Zinapsia for Odoo 19.
