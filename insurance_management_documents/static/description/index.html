Gestión de seguros - Documentos

Insurance files centralized in Documents

Bridge between Gestión de seguros and the Enterprise Documents app: installs automatically.

Key Features

  • Insurance folder: the files attached to policies and claims also become documents of the Insurance folder, tagged and with the insurer as contact.
  • Restricted access: the folder is shared only with the users the Documents administrator chooses; the files stay visible from the policies and claims for every insurance user.
  • Existing files: the files attached before the install are added on install.

Developed by Zinapsia for Odoo 19.
